# Audio Workflow

1. Inventory every game, UI, feature, win-tier, ambience, and error event.
2. Define asset names, duration, loop behavior, priority, polyphony, ducking,
   and reduced-intensity behavior.
3. Produce source masters and generate target codecs from those masters.
4. Bind audio only to deterministic game/frontend events.
5. Test rapid play, overlapping wins, mute/volume persistence, background-tab
   behavior, interruption, replay, and mobile hardware.
6. Record measured loudness, peak, memory, decode latency, and package size.

Do not let sound duration delay round settlement or required player controls.
